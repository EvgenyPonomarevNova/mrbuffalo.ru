# Локальная разработка

## Окружение

Docker Desktop (Linux containers) + PowerShell. Запуск из корня проекта:

```powershell
./scripts/local.ps1 up
./scripts/local.ps1 status
./scripts/local.ps1 check
./scripts/local.ps1 logs
./scripts/local.ps1 stop
```

Адрес: http://localhost:8088. Проект Compose: `mrbuffalo-local`. Порты соседних проектов: Inspector — 8085, Unitabs — 8086/8087; здесь используется 8088.

PHP 8.3 / Apache, MySQL 8.0 и nginx. Требования сверены с https://www.1c-bitrix.ru/products/cms/requirements.php и https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=32&LESSON_ID=2593. Расширения PHP и соединение с БД проверяет `check`; эта команда не подтверждает установку или лицензию CMS.

Только nginx публикует HTTP на `127.0.0.1`. PHP и MySQL находятся во внутренней сети без исходящего доступа. Локальная почта отключена. Проверки внешних соединений в мастере CMS, обновления и Marketplace в этом окружении работать не будут. Для них позднее потребуется отдельная конфигурация сети.

Тома `mrbuffalo-local_site` и `mrbuffalo-local_database` сохраняют ядро, upload и БД при остановке/пересоздании контейнеров. Не удалять тома и не выполнять `down -v`, если нужны данные. Папка `local/` подключена для собственного кода только на чтение; редактировать её нужно в репозитории.

## Поддомены и QR

Технические адреса: `http://product-01.localhost:8088/` … `http://product-08.localhost:8088/`. Современный браузер обычно направляет `.localhost` на loopback. Если системный resolver этого не делает, для CLI использовать `curl.exe --resolve product-01.localhost:8088:127.0.0.1 http://product-01.localhost:8088/`, а для браузера добавить нужные имена в hosts.

Прокси сохраняет исходный Host вместе с портом. Пока все адреса показывают общую техническую страницу: различение продуктов и интеграция с CMS будут реализованы после получения списка SKU. Передний QR — корень соответствующего поддомена, задний — `/#description`. Имена `product-01` … `product-08` временные и не предназначены для печати.

## Установка Битрикса

Ядро и лицензия пока не установлены. Чужие ядра, ключи и базы не копируются. После выбора редакции нужно скачать её чистый дистрибутив с https://www.1c-bitrix.ru/download/cms.php в игнорируемую `.local/`, распаковать в отдельный том сайта и пройти мастер установки. Редакцию «Старт» не считаем окончательно выбранной.

Доступы новой базы: сервер `db`, база `mrbuffalo`, пользователь `mrbuffalo`. Пароль — `DB_PASSWORD` в `.local/.env`. В мастере использовать существующую базу; root-пароль для CMS не нужен. Администратора CMS создать отдельно. Не публиковать пароли и ключ.

Скрипт первого старта создаёт технический `index.php` только в пустом томе; существующий сайт не перезаписывает. При установке дистрибутива этот начальный файл можно заменить файлом из официального архива.

## Git и материалы

`main` — начальная стабильная конфигурация, `dev` — дальнейшая работа. `.local/`, `.env*`, `bitrix/`, `upload/`, архивы, дампы, `исходники/` и `sources/` исключены из Git. В публичный репозиторий отправляется только собственный код и обезличенная документация.

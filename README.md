# Mr Buffalo

Восемь связанных продуктовых лендингов на поддоменах с единым шаблоном. Предварительная CMS — 1С-Битрикс. Сейчас подготовлены репозиторий и отдельное локальное окружение; дизайн ожидает референсов упаковок.

```powershell
./scripts/local.ps1 up
./scripts/local.ps1 check
```

Открыть http://localhost:8088. Docker Desktop должен быть запущен в режиме Linux containers. Скрипт сам находит Docker в стандартной папке Windows и создаёт локальные пароли.

- [Продукт и схема QR](PRODUCT.md)
- [Локальная разработка и установка ядра](docs/local-development.md)
- [Правила проекта](AGENTS.md)

Ядро Битрикса, база, ключи и исходники заказчика не входят в публичный репозиторий. Настройка production и DNS выполняется отдельно.

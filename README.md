# Mr Buffalo — визуальный концепт

Автономный демонстрационный лендинг первого продукта. HTML, CSS, vanilla JS.

Изображения реконструированы по упаковке для концепта; точность оригинальной фотографии и печатного макета не гарантируется. Маркетплейсы и форма демонстрационные, данные формы не отправляются. Исходники заказчика, CMS и локальные инструменты не включены.

Публикация: GitHub Pages, ветка `gh-pages`, корень `/`.
